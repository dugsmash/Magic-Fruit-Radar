# 🧙 远行商人闹钟 · 可点击移动端原型

> 《洛克王国》远行商人商品提醒 App 概念原型 —— 预设心愿单，稀有商品（棱镜球 / 祝福吊坠 / 炫彩精灵蛋…）出现时通过**消息 + 声音 + 震动**提醒你上线抢购。

## 🚀 快速体验

| 方式 | 操作 |
|---|---|
| **直接打开** | 双击 `index.html`（推荐 Chrome / Edge） |
| **本地服务** | `python -m http.server 8000` 后访问 `http://localhost:8000` |
| **手机预览** | 把本目录放到手机可访问的地址，或浏览器开发者工具切换手机视口 |

> 原型是纯前端（HTML/CSS/JS，零依赖），数据存 localStorage，**无需网络**即可完整体验。

## 📱 原型包含的界面

1. **许愿单（首页）** —— 已订阅商品列表 + 全局开关（消息/声音/震动/上课免打扰）+「模拟到货」按钮
2. **商品图鉴** —— 按稀有度筛选、搜索，10 件示例商品（棱镜球、祝福吊坠、炫彩精灵蛋、圣光护盾…）
3. **提醒记录** —— 提醒统计（今日/已上线/稍后提醒）+ 时间轴
4. **我的 / 设置** —— 提示音选择（清脆/魔法/静音）、震动模式、上课免打扰、区服切换、**四维调研结论**

## 🎁 通知模拟体验（核心演示）

点击首页「🎁 模拟：愿望商品到货！」：

- 🔔 **消息**：顶部滑出系统风格通知卡片，含商品名、剩余窗口倒计时、库存、操作按钮
- 🔊 **声音**：Web Audio 合成提示音（可切换"清脆叮咚 / 魔法之音 / 静音"）
- 📳 **震动**：调用 `navigator.vibrate`（手机浏览器/Android 真机可感，桌面无震动硬件时静默）
- 🏫 **上课模式**：开启后通知静音、不震动，仅横幅提示（学生党刚需）
- ⏰ **稍后提醒**：模拟 10 分钟后二次提醒，演示"兜底不轰炸"的通知策略

## 🧠 四维调研结论（多智能体协同产出）

### 1. 可行性 ✅（技术可行，数据源是核心变量）

- **官方公开 API 不存在**；可行数据源按可靠度：社区 API（如"洛克魔法书"付费 Key）→ 页面/协议轮询 → 截图 OCR → 众包上报 → 手动录入
- 检测延迟：社区 API 分钟级；页面轮询秒~分钟级；OCR 秒级（依赖截图来源）；众包分钟~小时级
- 技术风险：非官方接口易失效、抓取有反爬/账号风控风险、推送受厂商通道限制、随机规则复杂存在误报漏报
- 合规风险：非官方接口可能违反游戏用户协议；自动化抓取有不正当竞争/侵权风险；推送需符合个保法授权
- **结论**：MVP 用"社区数据源 + 页面轮询 + 众包上报"验证真实需求，不押注非官方接口；长期争取官方授权

### 2. 成本 💰（MVP 一次性约 $9,000，月度约 $115）

| 一次性 | 金额 | 月度 | 金额 |
|---|---|---|---|
| App 开发（外包） | $8,000 | 轻量云服务器 | $30 |
| UI / 图标设计 | $800 | 数据 API / 抓取节点 | $25 |
| 软著登记 + 上架 | $200 | 推送通道 | $10 |
| 合计 | **≈ $9,000** | 维护工时 | $50 → **≈ $115/月** |

> 个人自研可降至 $1,500 内；省钱路径：先 HTML 原型验证 → 免费推送通道（FCM/厂商免费层）→ 自研降本

### 3. 受众 🧑‍🤝‍🧑（明确蓝海）

- **画像**：16~30 岁玩家（05后~10后新玩家 + 情怀回归老玩家 + 代管家长）；收集党/强度党最痛
- **痛点**：商人出现完全随机（每天约 1~4 轮）、窗口短库存少、游戏内无提醒、攻略站要主动刷新、社区工具门槛高（GitHub Actions + 付费 API Key 普通人根本不会用）
- **竞品**：网页实时查询（18183、rocodex 等，无推送）、GitHub 提醒器 roco-merchant-notifier（需自建部署）、洛克魔法书（付费数据服务）、洛克捕手（抓包有封号风险）——**应用商店没有"心愿单+系统推送"的普通玩家向 App**
- **价值主张**："你的远行商人闹钟——想要的道具，出现时叫你上线"

### 4. 界面 🎨（低打扰的确定性提醒）

- 四 Tab：**许愿单 / 商品图鉴 / 提醒记录 / 我的**；推送→上线的路径 ≤ 2 步
- 打扰分级：普通商品=仅横幅，重要商品=声音+震动；一次推送+二次确认（稍后提醒 10/30 分钟）
- **上课免打扰是刚需**（不是附加功能）；多区服订阅支持老玩家
- 视觉：奶油暖黄底 + 魔法紫 + 暖橙；大圆角毛绒卡片；稀有度五档渐变（白/绿/蓝/紫/金）**必须配文字标签**；倒计时用"还剩 X 分钟"自然语言 + 呼吸感动效
- 无障碍：通知可被读屏完整朗读；声音/震动独立开关；防频闪；家长模式限制提醒频率
